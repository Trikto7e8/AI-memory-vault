# Contribuire

[English](CONTRIBUTING.md) | [Italiano](CONTRIBUTING.it.md)

Grazie per l’interesse verso Memoria Vault. Il progetto è ancora nella fase concettuale: discussioni e revisioni di progettazione sono particolarmente utili.

## Prima di proporre una modifica

- Per una modifica sostanziale, apri prima una issue spiegando il problema e la soluzione proposta.
- Non inserire dati personali reali, registrazioni, file del vault, credenziali o esportazioni di account nelle issue, nelle pull request o nei dati di test.
- Mantieni precise le affermazioni su privacy e sicurezza. Spiega cosa un attaccante o un servizio potrebbe comunque vedere.
- Per modifiche a cifratura, gestione delle chiavi, sincronizzazione, importazione/esportazione o audio, descrivi l’impatto sul modello delle minacce e chiedi una revisione di sicurezza.
- Preferisci modifiche piccole, verificabili separatamente.
